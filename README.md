# 🐾 ແມວລາວ NekoLao — ສວນປະຕູໄຊ ວຽງຈັນ 3D (Issarapon School Edition)

3D casual cat exploration & speedrun game set in **Patuxay Park, Vientiane, Laos**, built with **Three.js + TypeScript + Vite**.

## ✨ Features
- **Issarapon School Edition (`ໂຮງຮຽນ ອິດສະຫຼະພອນ`)**: Custom 3D park welcome signboards and golden-framed plaques on all 18 park benches.
- **100% Lao Language (`ພາສາລາວ`)**: Full localization using `Noto Sans Lao`.
- **Speedrun Timer & SNS Share**: Tracks time from pressing **Start Game (`▶️ ເລີ່ມເກມ`)** until clearing all 30 *Dok Champa* flowers & 6 Cat Mischief tasks, with center-screen clear time display (`X ນາທີ XX.X ວິນາທີ`) and 1-tap sharing to X, LINE, Facebook, Web Share, and PNG Certificate download.
- **Mobile & Desktop Ready**: Virtual analog thumbstick, multi-touch camera orbit & pinch-to-zoom, and keyboard/mouse controls.
